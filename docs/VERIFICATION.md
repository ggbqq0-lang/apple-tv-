# 验证范围

0.5.0（2026-10-16）本机检查：Python 47 项、JVM 53 项通过，零失败、零跳过；14 组 Kotlin RTI 数据由 Python 独立解码核对。Debug 与 Release 构建、Android Lint 完成，Lint 零错误。

覆盖配对、加密与签名校验、分帧、Unicode、整段替换/追加、默认同步绑定、输入框改变时停止、最后一笔编辑先于遥控、回读异常不继续确认、不自动重发、慢 ACK 下及时松开、长按释放和有界移动队列。

手机上已检查 Release 关闭调试、签名有效、覆盖安装保留配对、启动自动连接；键盘页方向区在输入法上方。用户在 Android 16 与 Apple TV 4K 第三代报告滑动/触感、长按删除并松手停止、默认实时输入和键盘页操作正常。此为用户整体观察，没有逐次按键的独立计时。

未完成所有 tvOS 应用、所有设备、多电视、Wi-Fi 切换与全部长文本的真机矩阵。密码框出现圆点不能证明明文逐字符一致。协议模拟测试不代表真实电视或业务表单已验收。
