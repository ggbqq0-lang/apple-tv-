# 安装与使用

下载 Releases 中的 APK，或解压分享 ZIP 后打开 APK。安卓按提示允许当前文件管理器/浏览器“安装未知应用”。无需开发者模式或 USB 调试。

手机与 Apple TV 接入同一局域网，唤醒电视。打开应用的“设备”页，选择电视并填写电视当前显示的四位码。每台手机需自行配对，安装包不携带维护者的电视记录。

首页圆盘中央确定、外圈点方向、全盘滑动。中央和独立确定可按住，松手停止；电视键盘选中退格后按住确认可连续删除。返回和 TV 可长按。

先在电视选中要输入的文本框并显示键盘，再进入手机“键盘”页。默认实时同步，中文确认选字后发送。输入后直接用下方方向和确认操作电视“完成”或“搜索”；使用遥控后同步暂停，再次输入可重开开关。

更新直接覆盖安装，不要先卸载。源码构建使用自己的签名，不能覆盖 Releases 维护者签名包。

找不到电视：检查同一局域网、访客网络/设备隔离、VPN 是否放行局域网及电视是否唤醒。手动连接需使用实际 Companion 端口，不能使用 AirPlay 端口代替。静音灰显表示当前输出无法确认支持网络静音；音量加减是独立能力。

回读不同或发送中断：先查看电视实际内容再决定是否发送，应用不会自动重复文字。反馈只提供公开测试文字，不提供账号密码、配对码、凭据或真实订阅地址。
